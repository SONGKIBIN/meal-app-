# 직원 식사 신청 시스템

직원들이 사번+이름으로 로그인해서 주간 달력에서 중식/석식을 신청·취소하고,
관리자는 일일/월간 신청 인원을 집계하고 엑셀로 내려받거나 인쇄할 수 있는 웹 애플리케이션입니다.

## 설치 방법

프로그래밍 지식이 없어도 따라 할 수 있도록 정리한 설치 가이드를 함께 받으셨을 것입니다.

**`식사신청시스템_설치가이드.docx`** 파일을 열어 1단계부터 순서대로 진행해주세요.
(GitHub 업로드 → MongoDB Atlas 생성 → Render 배포 → 관리자 초기 설정 → 직원 안내, 총 5단계)

직원들에게는 **`직원용_이용안내.docx`** 를 함께 전달하면 됩니다.

이미 운영 중인 시스템을 업데이트(기능 추가)하는 방법은
**`업데이트_배포가이드.docx`** 파일을 참고해주세요.

## 주요 기능

- 사번 + 이름 로그인 (한국어 / English / 中文 지원), 로그인 성공 시 사번/이름을 기기에 저장해두었다가
  다음 접속 때 입력칸에 자동으로 채워줌
- 로그인 후 화면 상단 "접속 링크 공유" 버튼으로 사이트 주소 복사 및 QR코드 공유 가능
- 주 단위(월~일) 캘린더에서 중식/석식 개별 신청·취소
- 당일 신청·취소 마감시간 자동 적용 (설정한 시각까지는 신청/취소 모두 가능,
  중식/석식 마감시간을 서로 다르게 설정 가능하며, 관리자 화면의 "설정" 탭에서
  재배포 없이 바로 변경 가능)
- 관리자: 직원 관리(엑셀 일괄 등록/템플릿 다운로드, 이름/사번/부서 검색),
  신청 현황 강제 수정, 미신청 직원 목록, 일일/월간 집계, 엑셀 다운로드, 인쇄
- 시스템 최초 설치 시 자동 생성되는 마스터 관리자 계정(기본 사번 admin)만 "내 식사 신청" 메뉴 없이
  관리자 화면만 보이고 인원 집계에서도 제외됨. 다른 직원에게 나중에 부여한 관리자 권한은 예전과 동일하게
  관리자 화면 + 식사 신청 화면을 모두 사용하고 인원 집계에도 포함됨
- 일일 집계: 중식/석식별로 신청자 명단과 미신청자 명단을 구분해서 확인 가능,
  일반직원/도급직원 인원을 나누어 보여주고 합계도 함께 표시 (월간 집계도 동일)
- 직원 관리 화면 상단에 개인 인원 / 도급사 총원(TO) / 합계를 요약 카드로 표시,
  부서별·가나다순·사번별·재직자별 정렬과 재직자/퇴직자 구분 보기 지원,
  퇴직 처리된 직원은 "복직" 또는 기록까지 영구 제거하는 "완전 삭제" 가능
- 도급회사(단체) 계정: 직원을 "도급" 구분으로 등록하면 개별 신청 대신
  인원수를 숫자로 입력해 일괄 신청·수정·취소(0 입력) 가능. 총 인원(TO)을 설정해두면
  (TO - 신청 인원)만큼을 미신청 인원으로 자동 집계하여 신청현황/일일집계에 반영.
  도급팀 로그인 화면에서 등록된 TO를 직접 확인하고, TO가 실제와 다르면
  "총원 수정 요청"으로 관리자에게 바로 수정을 요청할 수 있으며 관리자가 승인/거절 처리
- 일일 집계 화면에서도 미신청 인원(중식/석식)을 함께 확인 가능
- 주간 식단표 게시(이미지 업로드 또는 텍스트, 이번 주/다음 주는 날짜 기준으로 자동 갱신되며,
  8주가 지난 지난 식단표는 자동 삭제), 공지사항 팝업 게시
  (설정 탭에서 게시한 공지를 종료하거나 완전히 삭제 가능)
- 당일 미신청자에게 신청 화면 접속 시 자동 신청 안내 팝업
- 관리자 데이터 백업(전체 직원/신청내역을 JSON 파일로 다운로드)
- 휴대폰 알림(웹 푸시): 마감 임박 알림, 관리자 일일 집계 알림
- PC/모바일 반응형 + PWA(홈 화면/바탕화면에 앱처럼 설치 가능, 설치 버튼 제공)
- 신흥정밀(SHC) 로고 적용 (헤더, 로그인 화면, 브라우저 파비콘, PWA 앱 아이콘)

## 로컬에서 직접 실행하고 싶은 경우 (선택, 개발자용)

```bash
npm install
cp .env.example .env   # .env 파일을 열어 실제 값 입력
npm start
```

## 환경변수

`.env.example` 파일 참고. 배포 시에는 Render의 Environment 설정 화면에 동일한 값을 입력합니다.

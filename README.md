# 직원 식사 신청 시스템

직원들이 사번+이름으로 로그인해서 주간 달력에서 중식/석식을 신청·취소하고,
관리자는 일일/월간 신청 인원을 집계하고 엑셀로 내려받거나 인쇄할 수 있는 웹 애플리케이션입니다.

## 설치 방법

프로그래밍 지식이 없어도 따라 할 수 있도록 정리한 설치 가이드를 함께 받으셨을 것입니다.

**`식사신청시스템_설치가이드.docx`** 파일을 열어 1단계부터 순서대로 진행해주세요.
(GitHub 업로드 → MongoDB Atlas 생성 → Render 배포 → 관리자 초기 설정 → 직원 안내, 총 5단계)

직원들에게는 **`직원용_이용안내.docx`** 를 함께 전달하면 됩니다.

## 주요 기능

- 사번 + 이름 로그인 (한국어 / English / 中文 지원)
- 주 단위(월~일) 캘린더에서 중식/석식 개별 신청·취소
- 당일 신청 마감 09:30, 당일 취소 불가 규칙 자동 적용 (환경변수로 조정 가능)
- 관리자: 직원 관리(엑셀 일괄 등록/템플릿 다운로드), 신청 현황 강제 수정,
  일일/월간 집계, 엑셀 다운로드, 인쇄
- PC/모바일 반응형 + PWA(홈 화면/바탕화면에 앱처럼 설치 가능)

## 로컬에서 직접 실행하고 싶은 경우 (선택, 개발자용)

```bash
npm install
cp .env.example .env   # .env 파일을 열어 실제 값 입력
npm start
```

## 환경변수

`.env.example` 파일 참고. 배포 시에는 Render의 Environment 설정 화면에 동일한 값을 입력합니다.
